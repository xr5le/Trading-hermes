# trading-expert-ar: Skill خبير تداول بالعربية لـ Claude

Skill لـ Claude تجعله يجيب كخبير تداول باللغة العربية، من ملخص مكثف لمفاهيم:
- البنية والسيولة والأوردر بلوك ومصفوفة PD Arrays (ICT/SMC)
- Order Flow و IPDA و MMXM
- الانحياز خارج الشارت: COT، السندات والفائدة، DXY و SMT، الموسمية، دورة الأعمال
- الوقت و Kill Zones، و ICT Intraday
- إدارة المخاطرة والنفسية، وبناء الاستراتيجية واختبارها إحصائياً

## التثبيت
1. حمّل ملف [`trading-expert-ar.zip`](trading-expert-ar.zip) من هذا المستودع.
2. في Claude: Settings ← Capabilities ← Skills ← Upload skill، وارفع الملف كما هو.
3. في Claude Code: ضع المجلد في `~/.claude/skills/trading-expert-ar/`.

## تنبيه
- محتوى تعليمي فقط، وليس نصيحة مالية أو توصية بالشراء أو البيع. التداول فيه مخاطرة عالية.
- هذا الملخص مكتوب بكلماتنا، ولا يحتوي نصوص أو مواد أي دورة. المشروع غير تابع لأي دورة أو مدرب مذكور.
